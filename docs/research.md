## 1. 參考作品拆解:kypk1219/wpiphone

- 網址:https://kypk1219.github.io/wpiphone/ ;原始碼:https://github.com/kypk1219/wpiphone
- 主題:「김원필의 iphone」— 撿到 DAY6 원필(設定為鋼琴學院院長)的手機,從手機裡的紀錄拼湊他與 영현 之間的故事。說明文字:「아이폰 속 기록을 따라가는 가상의 이야기」。
- **授權:repo 沒有 LICENSE → 預設保留所有權利。** 我們只參考「玩法與結構」,程式碼、文字、圖片全部自己做。

### 1.1 技術
- Next.js 16 + React 19 + Tailwind 4 + shadcn,`output: 'export'` 靜態輸出,GitHub Actions 部署到 Pages。
- 字型 Noto Sans KR;全站韓文。
- 進度存在 `sessionStorage`(重新整理會延續,關分頁重來);設定 App 裡有「스토리 다시 시작」。
- 桌機顯示成 390×844 圓角 iPhone 外框;手機上全螢幕。
- 有音效(카톡 提示音,第一次點擊後才解鎖音效,符合瀏覽器規則)。

### 1.2 遊玩流程
1. **鎖定畫面**:日期「11월 19일 수요일」、時間 18:57、桌布,通知欄顯示一則簡訊。
2. **密碼(1219)**:提示藏在鎖屏通知——一則「캐치콜」簡訊寫著 영현 的號碼 010-**1219**-0482。答錯會震動並清空。
3. **主畫面**:兩頁 App + Dock,有小工具。
4. **解鎖 0.9 秒後劇情開始**:영현 傳來「퇴근 안했지?」橫幅通知。
5. **事件鏈**:
   - 打開 영현 聊天室 → 1.2 秒後 우준영 傳「나 학원 주차장 도착했어요~」。
   - 영현 打來電話(來電畫面);玩家掛斷 → 時間跳到 18:58,連續收到「전화 왜 끊어」「보고 있는 거 다 알아」等橫幅。
   - 進聊天室再收到「너 우준영 만난 건 아니지」→ **此時玩家才能打字回覆**。
6. **分支回覆**:玩家輸入的文字比對一大串關鍵詞(各 80 多句):
   - 否認(아니/안 만났어…)→ 分支 A:「알았어 / 그럼 일단 학원 주차장에서 기다려」
   - 承認(만났어/같이 있어…)→ 分支 B:「김원필 / 그 새끼 만나지마 / 나 지금 가고 있다고」
   - 比對不到 → 訊息顯示「1」未讀,對方不讀。分支一旦決定就固定。
   - 우준영 的聊天室也有同樣的 A/B 分支。
7. 沒有明確「結局畫面」,而是讓玩家在各 App 裡自己拼湊背景。

### 1.4 值得學的設計手法
- **密碼藏在鎖屏通知裡**,不用額外提示。
- **時間凍結**在某一分鐘,所有紀錄以「今天/昨天/日期」相對顯示,很像真手機。
- **劇情由玩家行為觸發**(開哪個聊天室、接不接電話),不是單純看圖文。
- **限制打字時機**:只有劇情問到你時才能回,避免玩家亂打。
- **關鍵詞分支 + 未讀「1」**,營造「對方在等你回答」的壓力。
- 細節:App 角標數字、已讀狀態、廣告訊息、Wi-Fi 名稱,這些「雜訊」才是真實感來源。
- 原作調性偏暗(分手、執著、跟蹤感)。**我們改成溫暖、甜的兄弟/CP 粉絲向。**

## 3. 我們的版本:規格草案

### 3.1 結構
- 首頁選擇:**「신유의 iPhone」/「도훈의 iPhone」**,右上角切換 **한국어 / 中文**。
- 每支手機是一條獨立劇情,用同一套手機外殼,只換資料。
- 語言:韓文是正本;中文版是同一套資料的翻譯欄位(不另寫劇情)。

### 3.2 신유의 iPhone(暫定)
- 時間凍結:**1월 30일 23:58**(도훈 生日前兩分鐘)。
- 密碼 `0130`:鎖屏通知是行事曆提醒「🎂 도훈이 생일 (내일)」或鬧鐘「0130 🐺」。
- 主線:신유 正在準備午夜零點傳給 도훈 的生日訊息(備忘錄裡有草稿,改了好幾版)。
- 事件:00:00 一到 → 도훈 先傳來「형 안 자?」→ 玩家幫 신유 回覆(分支:溫柔/嘴硬)。
- App 內容:
  - 카톡:유도즈 聊天室(保齡球、借鞋照、「구석으로 와」梗)、TWS 群組、경민 / 지훈 私訊
  - 메모:生日信草稿、保齡球比分紀錄
  - 사진:用插畫/色卡代替照片,如「借來的鞋子」「練習室鏡子」
  - 검색 기록:「두바이 쫀득쿠키 파는 곳」「볼링 잘 치는 법」「동생 생일 선물 추천」
  - any ai:「무뚝뚝한 동생한테 생일 편지 쓰는 법」

### 3.3 도훈의 iPhone(暫定)
- 時間凍結:**11월 7일 00:00 前後**(신유 生日)。
- 密碼 `1107`:提示放在通知或桌布小工具。
- 主線:도훈 偷偷準備 신유 的生日驚喜(蛋糕、成員群組密謀)。
- 事件:신유 突然傳訊「도훈아 뭐해」→ 玩家要幫 도훈 瞞住驚喜(分支:裝傻/露餡)。
- App 內容:成員密謀群組、手指愛心的回憶備忘、搜尋「형 생일 서프라이즈」、語音備忘(練習中的生日歌)。

### 3.4 原則
- 素材:**不用官方照片或影片**;頭像用 emoji 或自繪插畫(🐺 等)。
- 調性:溫暖、甜、搞笑,不寫私生活、戀愛露骨或負面情節。
- 頁尾標示「팬메이드 · 비공식 · 허구의 이야기」。
- 技術:純靜態網站(Vite + React,或零框架 HTML/JS),手機優先,部署到本 repo 的 GitHub Pages。
- 原作的程式碼不複製,自己實作同類機制:鎖屏、密碼、橫幅、事件觸發、關鍵詞分支、未讀、重來。
