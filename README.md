# 유도즈의 iPhone

TWS 신유·도훈(유도즈)을 모티브로 한 팬메이드 "주운 폰" 인터랙티브 웹. 한국어 원문 + 중국어(繁體) 번역.

- **신유의 iPhone**:1/29 23:58,도훈 생일 2분 전 (비밀번호 힌트는 잠금화면 알림)
- **도훈의 iPhone**:11/6 23:57,신유 생일 서프라이즈 직전

> 비공식·허구의 이야기입니다. 실제 인물·소속사와 관계없습니다.

## 조작법

| 동작 | 방법 |
|---|---|
| 잠금 해제 | 잠금화면을 위로 쓸어올리기 → 암호 입력 (키보드 숫자도 가능) |
| 홈으로 | 화면 맨 아래 바를 위로 쓸어올리기 (또는 탭) |
| 뒤로 가기 | 앱 안에서 왼쪽 가장자리를 오른쪽으로 밀기 |
| 제어 센터 | 오른쪽 위(배터리 쪽)에서 아래로 끌어내리기 |
| 알림 센터 | 왼쪽 위(시계 쪽)에서 아래로 끌어내리기 |
| 알림 배너 | 탭하면 해당 채팅방, 위로 밀면 닫기 |

제어 센터·설정의 에어플레인/Wi-Fi/블루투스/무음/방해 금지/밝기/음량, 배경화면, 언어는 실제로 반영됩니다.
카메라는 기기 카메라를 사용하고(권한 거부 시 가상 화면), 찍은 사진은 사진 앱에 들어갑니다.
전화 앱 키패드로 번호를 누르면 발신 화면이 뜨고, 시계 앱의 스톱워치·타이머는 실제로 동작합니다.

## 직접 해볼 수 있는 것

- **카톡**: 아무 방에서나 메시지를 보내면 사람마다 성격대로 답장해요(단톡은 한두 명이 대답). `+`로 앨범 사진 보내기, 😀로 이모티콘 보내기, 방 위쪽 📞로 바로 전화.
- **전화·페이스톡**: 연락처·최근 기록·키패드·카톡 프로필에서 걸 수 있어요. 받는 사람은 자막으로 말하고, 안 받는 사람은 나중에 카톡을 보내요. 페이스톡은 내 카메라가 켜져요.
- **iMessage**: 메시지 앱 ✏️ → 받는 사람 고르기. 입력 중 표시 후 답장이 와요.
- **Instagram DM**: 멤버에게 보내면 답장이 와요.
- **음성 메모**: 빨간 버튼으로 실제 녹음·재생 (마이크 권한 필요).
- **메모**: ✏️로 새 메모 작성·삭제 (브라우저에 저장).
- 키워드 답장 내용은 `src/story/personas.ts`에서 고칠 수 있어요.

## 앱 & 숨겨진 비밀

홈 화면 2페이지(좌우로 넘기기)에 Instagram · X · 음악 · 지도 · 메일 · 날씨가 있습니다.
폰마다 비밀 5개가 숨어 있고, 찾으면 알림이 뜨며 설정 → "발견한 비밀"에서 진행도를 볼 수 있어요.

| 비밀 | 찾는 법 (스포일러) |
|---|---|
| X 비밀 계정 | X 왼쪽 위 프로필 → 계정 전환 |
| 잠긴 메모 | 메모 앱의 🔒 메모. 암호 힌트는 메일·X 비밀 계정·Instagram 소개에 |
| 가려진 앨범 | 사진 → 앨범 → 가려진 항목 (폰 암호) |
| 최근 삭제된 사진 | 사진 → 앨범 → 최근 삭제된 항목 |
| 보내지 않은 메일 | 메일 → 임시 저장 |

## 전체 화면

- Android · PC: 첫 화면의 "전체 화면으로 보기" 버튼이나 설정 → 전체 화면 토글. 휴대폰에서는 폰을 고르는 순간 자동으로 전체 화면이 됩니다.
- iPhone: Safari가 웹 전체 화면을 지원하지 않으므로 공유 → "홈 화면에 추가" 후 아이콘으로 열면 앱처럼 전체 화면으로 열립니다.

## 사진 넣기

지금은 사진 자리에 이모지 카드, 프로필에는 카카오톡식 기본 프로필이 나옵니다.

1. 이미지를 `public/photos/` 아래에 넣습니다. 예: `public/photos/shinyu/p2.jpg`
2. `src/story/shinyu.ts` 또는 `dohoon.ts`에서 해당 항목에 경로를 적습니다(앞에 `/` 없이).
   - 앨범 사진: `photos` 항목에 `src: 'photos/shinyu/p2.jpg'`
   - 카톡 사진 메시지: `{ ..., photo: {...}, src: 'photos/shinyu/shoes.jpg' }`
   - 프로필 사진: `contacts.dohoon` 에 `avatar: 'photos/avatars/dohoon.jpg'`, 폰 주인은 `owner.avatar`

### 스크립트 문법

`script`의 트리거는 `when` 이벤트가 일어나면 `actions`를 순서대로 실행합니다.

- 이벤트: `unlock`, `open:<방id>`, `branch:<방id>`, `branch:<방id>:<분기id>`, `call:accepted`, `call:declined`, `call:done`
- 액션: `msg`(메시지 도착), `clock`(시각 변경), `reply`(답장 대기 + 키워드 분기, 키워드 `''`는 아무 말이나), `call`(전화 수신), `wait`
